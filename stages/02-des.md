# Этап 2. Дискретно-событийная модель

[Модель CrowdfundingPlatform.alp](../models/des/CrowdfundingPlatform.alp) использует Process Modeling Library. Для каждого R1–R8 цепочка Enter → TimeMeasureStart → Service → TimeMeasureEnd → Exit измеряет посещение. Занятость интегрируется по изменениям, вход и начало обработки фиксируют ожидание. В панели 2D выводятся счётчики и таблица ресурсов, в 3D высота столбца отражает текущую очередь.

## Проверка масштабного прогона

Базовый сценарий AnyLogic PLE 8.9.8 с seed 2501 остановился по счётчику на **10 000 завершённых проектах** через **2019,397 ч**, раньше предела 2160 ч. Из 10 096 поступивших проектов 96 оставались незавершёнными. Выплатили 9590 проектов, технических отказов было 158. Обработка включала 152 461 запись платежа и 5504 повторные попытки. Принимаемые посещения обслуживаются повторно используемыми техническими агентами. В прогоне создано 374 носителя.

- Пропускная способность — 4,952 завершения и 4,749 выплаты/ч.
- Взвешенная по каналам загрузка — 56,47%.
- Зрелое SLA модерации нарушено для 1762 из 10 049 проектов, или 17,53%.
- Среднее время полного цикла завершённых проектов — 15,69 ч, P95 — 31,95 ч. Порог SLA применяется к участку модерации, у которого отдельное измерение.
- Денежный баланс в копейках: 123 878 914 = 122 607 557 выплаченных + 855 346 возвращённых + 416 011 удержанных.

Проверка выгрузки покрывает проектный и денежный баланс, восемь ресурсов, монотонность времени трасс, пределы занятости, баланс заявок в каждом R и отработку счётчика остановки. [Журнал](../results/native/research/audit.txt), [метрики](../results/native/research/metrics.csv), [ресурсы](../results/native/research/resources.csv)

## Условия остановки

Диагностический прогон с лимитом 2 завершился после двух исходов. В отдельном нативном прогоне с тремя заданными проектами лимит по числу не достигнут, расчёт завершился по горизонту 2160 ч. Все 4000 зачисленных копеек выплачены. Это проверка ограничителя времени при заданных проектах. Стохастический исследовательский результат приведён выше. [Лимит 2](../results/native/count/audit.txt), [горизонт 2160 ч](../results/native/horizon-diagnostic/audit.txt)
