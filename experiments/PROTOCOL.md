# Протокол сравнения мощности

Пилот seed 2501 с основным правилом остановки занял 5,86 с вместе со стартом Python. Для 120 прогонов оценка составляет около 12 минут суммарного процессорного времени. Проверяются 12 конфигураций по 10 повторений с seeds 2501–2510 в пустой системе на одинаковом горизонте 2160 часов. Основной прогон находится в `results/raw/des_baseline.json`. Сравнение парное по seed, точность оценивается по 95% интервалам Стьюдента для средних повторений и парных различий. Направление эффекта подтверждено, если интервал парного различия целиком лежит по одну сторону нуля. Достаточность для подтверждения SLA определяется верхней границей интервала ниже 5%.

Разные загрузки, улучшение R2/R3/R4 и перераспределение сравниваются с базой. Сравнение с нативными результатами требует прогона AnyLogic. Серия `capacity.jsonl` относится к эталонному Python DES.
