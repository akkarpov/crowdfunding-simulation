## Двадцать вопросов

1. **Зачем четыре модели?** DES воспроизводит заявки и ресурсы, ABM — состояние и класс отдельного агента, SD — задержки агрегированных обратных связей, M/M/c/K — вероятность заполнения и среднюю очередь подсистемы.
2. **Как трактуются доли маршрутов?** Как вероятности сценария при создании. Дополнительная ручная проверка, поддержка и споры меняют фактические посещения.
3. **Что занимает канал R5?** Операция публикации или учёта платежа. Активная кампания сохраняет собственное состояние на протяжении сбора.
4. **Что распределено по Парето?** Сумма одного пожертвования. Интервалы поступления моделируются отдельно.
5. **Учитывает ли система реальный фрод в решении?** Скрытый признак используется только при генерации проверочного сигнала, а решение следует из наблюдаемого результата.
6. **Как предотвращается двойная выплата?** После конца приёма ждём все начатые платежи, затем флаг расчёта защищает единственную ветку выдачи средств.
7. **Как учитываются незавершённые заявки?** В зрелой когорте заявка без решения к порогу считается нарушением. У молодого проекта исход может быть неопределённым.
8. **Почему для SLA берётся 8 часов?** Это настраиваемое учебное допущение для технического решения в течение рабочего дня.
9. **Что означает P95?** Оценка квантиля наблюдаемых задержек. Умеренно и сильно цензурированные когорты следует сопровождать долей неизвестных.
10. **Чем подтверждено ограничение R3?** Парный эксперимент с одним дополнительным каналом сокращает среднюю очередь, P95 и нарушенный SLA на тех же seeds.
11. **Почему общие завершения почти не выросли?** В общий throughput входят и технические отказы. Меняется состав завершений, выплаты следует измерять отдельно.
12. **Сколько стоит рекомендуемый вариант?** 65 у.е. при учебных весах, на 3 у.е. выше базы. R2=1, R3=3, R4=4, остальные каналы заданы базовой конфигурацией.
13. **Достаточно ли одного seed?** Для сквозной проверки логики достаточно целевого примера. Для вывода о мощности использованы независимые повторения и парные разности.
14. **Откуда значения λ и μ?** λ — попытки входа в R3 на час в базовом DES, μ — обратная величина среднего времени канала.
15. **Существует ли стационарное распределение при λ>cμ?** Для конечной системы с положительными интенсивностями оно существует. Избыточные поступления блокируются при K.
16. **Что изменяет тяжёлый класс?** Время ручного обслуживания с множителем 2,5. Отношение ожидаемого объёма работы равно 1+1,5h для доли h.
17. **Прерывает ли приоритет работу над тяжёлым проектом?** Очередь меняет порядок только для ожидающих. Начатое обслуживание выполняется до конца.
18. **Почему SD не даёт индивидуального P95?** В накопителях нет индивидуальных времён прихода и завершения. Для квантиля нужна дополнительная модель задержек.
19. **Когда нужен пятый платёжный канал?** Прежде всего при цели ≤5% нарушений срока платежей в заданном учебном сценарии. Это повышает стоимость до 68 у.е.
20. **Как применить выводы к действующей платформе?** Откалибровать интенсивности и длительности по журналам, проверить распределение маршрутов и согласовать пороги SLA. Затем повторить контрольные сценарии на реальном диапазоне нагрузки.
