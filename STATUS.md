# Состояние проекта

## Проверка окружения

- AnyLogic PLE 8.9.8 установлен в `D:\AnyLogicPLE898`, в комплекте OpenJDK 17.0.9. Обнаружены библиотеки Process Modeling, 3D, примеры Statechart и SD, а также плагин и JAR OptQuest. Пока проверено наличие компонентов. Запуск, лимит агентов и доступ к конкретному решателю требуют фактической проверки.
- По документации AnyLogic PLE ограничивает анимированный прогон пятью модельными часами, а Design-time API поддерживается в Professional и University Researcher. Будут отдельно проверены запуск и ограничения установленного PLE. [Редакции и ограничения](https://www.anylogic.com/downloads/) · [Design-time API](https://www.anylogic.help/advanced/code/dt-api.html)
- Доступны Python 3.11.2, NumPy, SciPy, Matplotlib, python-docx и установленный Microsoft Word. Экспорт PDF пока не проверен.
- При запуске установленного AnyLogic с комплектным Bank появляется процесс. Снимок экрана через текущий сеанс возвращает «The handle is invalid». Факт открытия, сборки и прогона примера пока не подтверждён.
- Исходная папка была пустой. Оригинал задания преподавателя, отдельное описание системы и учебный материал по Оптнеру отсутствуют. Используются предоставленное ТЗ, его описание ресурсов и явно перечисленные допущения.
